Web bridge 2 chiều - LAN

Ví dụ: ws://192.168.1.100:8081/ws
Chưa kết nối
Bên dt1 đặt URL realtime trong BCR là: ws://IP-MAY-TINH:8081/ws?session=<session-id>
Web và dt1 phải dùng cùng Session ID.

Mở web trong LAN bằng: http://IP-MAY-TINH:8081/index.html

Lưu ý: nếu mở bằng HTTP thường trên một số điện thoại, trình duyệt có thể chặn mic web. Khi đó vẫn có thể test chiều nghe từ dt2 ra web trước.
