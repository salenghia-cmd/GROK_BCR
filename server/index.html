Chưa kết nối
Bên dt1 đặt URL realtime trong BCR là: ws://IP-MAY-TINH:8081/ws?session=<session-id>
Web và dt1 phải dùng cùng Session ID.

Nếu mở trang bằng iPhone qua http://192.168.x.x:8081/... thì nhiều máy sẽ không bật được mic web. Hãy dùng HTTPS hoặc test bằng Android Chrome / laptop Chrome.
